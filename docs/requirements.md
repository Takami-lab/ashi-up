# 要件定義：各動作のクリア判定条件（WBS 1）

作成日 2026-11-11 / 責任者：髙見仁人。**数値はすべてPoC用の暫定値で、医学的に検証された基準ではない**（第5回で数式を確定、WBS 8・9 で調整）。

## 0. 共通定義

画像座標は動画ピクセル（右が +x、下が +y）。ランドマーク番号は MediaPipe Pose（人物の解剖学的な左右）。

| 記号 | 定義 |
| --- | --- |
| `H_c` | 両腰（23, 24）の中点。基準姿勢での値 |
| `A_s` | 対象側の足首（右=28, 左=27）の現在位置。`A_s⁰` は基準姿勢での位置 |
| `L` | 脚長 = `‖腰_s − 足首_s‖`（基準姿勢の平均）。上下方向の物差し |
| `W` | 腰幅 = `‖腰_L − 腰_R‖`（基準姿勢の平均）。左右方向の物差し |
| `v(·)` | ランドマークの推定信頼度（visibility） |
| `T_hold` | 保持時間（既定 700 ms） |

### 基準姿勢（全動作共通）
全身（23〜28）が画面内で `v ≥ 0.5`、両脚の `腰.y < 膝.y < 足首.y`、直線性 `‖腰−足首‖/(‖腰−膝‖+‖膝−足首‖) ≥ 0.9`、左右の脚長比 ≥ 0.8、約1秒間の静止（ぶれ ≤ 0.08 L）を満たしたときの平均値。

### 共通の成立条件（全動作）
1. 対象足首が検出されている：`v(A_s) ≥ 0.5`
2. 動作固有の条件 `C` を満たす
3. `C` が **`T_hold` 連続**で成立（途中で外れたら 0 に戻す。フレーム間隔の加算上限 200 ms）
4. 立位の基準姿勢のままでは `C` が成立しない設計にする（誤CLEAR防止）

人物が大きく外れた場合：腰が見えない状態が 2 秒、または `‖H_c − H_c⁰‖ > 0.6 L` が 1.5 秒続いたら基準を取り直す。

## 1. 片足上げ（実装済み）

目標 `T = A_s⁰ + (0, −r_up · L)`、半径 `ρ = 0.15 L`、`r_up = 0.30`（暫定）

`C_raise : ‖A_s − T‖ ≤ ρ`（一度入ったら ρ×1.2 まで許容：ヒステリシス）

## 2. 横ステップ（右へ1歩→保持）

対象足：右（`side` で左に拡張可能）。外向き方向 `d = sign(A_s⁰.x − H_c⁰.x)`（右足が画像のどちら側かをカメラ向き・ミラーに依らず基準姿勢から決める）。

- 外向き移動量（腰幅比）：`s = d · (A_s.x − A_s⁰.x) / W`
- 接地の維持：`h = |A_s.y − A_s⁰.y| / L`
- 体幹のずれ：`b = ‖H_c − H_c⁰‖ / W`

`C_step : s ≥ s_min  かつ  h ≤ h_max  かつ  b ≤ b_max`

| パラメータ | 暫定値 | 意味 |
| --- | --- | --- |
| `s_min` | 1.0 | 足首が腰幅1つ分以上、外へ出る |
| `h_max` | 0.15 | 足を上げず接地したまま（片足上げとの区別） |
| `b_max` | 0.5 | 体ごと移動せず、足だけ踏み出す |

判定は共通の成立条件（`T_hold` = 700 ms 連続）に従う。Target表示は、`s = s_min` の位置に足首用の円（半径 0.15 L）を出す案とする（画面は `screens.md`）。

## 3. 動作間の進行（WBS 4 で実装）

片足上げ → 横ステップの順に各1回。各動作の結果は `success | timeout`（制限時間は第5回で決定。未決）を記録する。
