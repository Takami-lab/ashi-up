# 検証計画・記録（WBS 8）

目的：端末・カメラ位置ごとに、2動作（足上げ／横ステップ）が意図どおり判定されるかを確認する。検証は安全な場所で成人が行う。
公開URL：https://takami-lab.github.io/ashi-up/ （`?dev` を付けると fps・Target までの距離などが見える）

## 条件
- 端末：iPhone(Safari) / Android(Chrome) / iPad / PC(Chrome) のうち手元にあるもの
- カメラ位置：距離（約2m / 3m）・高さ（腰 / 胸）・角度（正面 / 斜め30°）
- 照明：明るい室内 / 暗め

## 手順（1条件あたり）
1. 全身（腰〜足首）が映る位置に立ち、基準姿勢が取れるか（「足を上げて」が出るまでの秒数）
2. 足上げ：Targetに合わせて 0.7 秒保持 → 成功するか。立位のままで成功しないか
3. 横ステップ：外へ踏み出して成功するか。立位のままで成功しないか
4. 判定の誤り（成功すべきで未達／成功すべきでないのに成功）と、そのときの `?dev` の値を記録
