# 画面構成・画面遷移（WBS 2）

方針：ライトテーマ、文字は最小限・大きく、操作は「開始」「やり直す」中心（現行PoCのUIを踏襲）。

## 画面一覧

| ID | 画面 | 表示 | 状態 |
| --- | --- | --- | --- |
| S1 | Start | アプリ名、「開始」ボタン | 実装済み |
| S2 | Training | カメラ映像、骨格、Target、指示文、進捗バー | 実装済み（動作ごとに指示文とTargetを切替：WBS 4） |
| S3 | Feedback | 動作ごとの結果（○ 成功 / × 未達成）、「やり直す」 | WBS 7 で実装（現行の Finish を拡張） |
| SE | Error | カメラ不可・読込失敗の大きな一文、「もどる」 | 実装済み |

## 遷移

```
S1 Start ─開始→ S2 Training[動作1: 足を上げて] ─成功/時間切れ→ S2 Training[動作2: 横に踏み出して]
                                                              └─成功/時間切れ→ S3 Feedback ─やり直す→ S2[動作1]
S2 ─カメラ不可→ SE Error ─もどる→ S1
```

- 動作の切替時は短い間（約1秒）に「次の動作」を示し、基準姿勢を取り直す（全身が映る立位に戻ってもらう）
- 指示文：動作1「足を上げて」／動作2「横に踏み出して」／姿勢待ち「全身を映して」「まっすぐ立って」
- 結果表示は記号と大きな文字のみ（例：足上げ ○、横ステップ ×）。履歴保存はしない（MVP外）
- 開発者パネル（`?dev`）は通常画面に出さない
